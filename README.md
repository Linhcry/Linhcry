# 刘琦 · Linhcry

关注机器人运动控制、强化学习、灵巧操作与工程算法，也做机械结构设计和算法平台开发。

## 代表项目

| 项目 | 做了什么 |
|---|---|
| [RoboCup T1 控制与强化学习](https://github.com/Linhcry/robocup-t1-control-lab) | 23 DoF 机器人运动控制、步态接入、PPO 实验与起身任务评测。 |
| [五指灵巧手书写仿真](https://github.com/Linhcry/dexhand-calligraphy) | 题目识别、笔画规划、机械臂 IK、抓笔与接触反馈、书写质量评估。 |
| [机器人舞蹈动作平台](https://github.com/Linhcry/robot-motion-platform) | 视频动捕、动作重定向、分阶段任务编排、运动诊断和多视图同步。 |
| [无人机应急运输联合优化](https://github.com/Linhcry/uav-disaster-optimization) | 异构无人机分配、路径定价、电池充电、通信约束和独立方案验证。 |
| [快递分拣机器人机械臂](https://github.com/Linhcry/parcel-sorting-arm-design) | 本科毕设：机械结构、伺服与传动选型、轴系校核和静力有限元分析。 |
| [冶炼过程视觉与在线分析平台](https://github.com/Linhcry/smelter-analytics-platform) | 整合终点判别、铁含量回归、图像数据管理、训练评估与过程回放。 |

本科期间主要承担的 [太阳能小车机构设计](https://github.com/Linhcry/solar-car-mechanical-design)，以及 [模块化机器人 CAD 自动化](https://github.com/Linhcry/modular-robot-pet) 也已整理公开。
